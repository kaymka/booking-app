# 🏨 Booking App

Приложение для бронирования с валидацией дат и городов.

## 🚀 Демо

[Открыть приложение](https://kaymka.github.io/booking-app/)

## 🛠 Технологии

- **TypeScript** — типизация
- **Vite** — сборка
- **Jest** — unit-тестирование
- **CSS3** — стилизация

## ✅ Тестирование

В проекте реализовано **30+ unit-тестов** для проверки валидации:

- Формат даты (ДД.ММ.ГГГГ)
- Корректность дат (30/31 день, февраль, високосные годы)
- Валидация городов
- Граничные случаи и ошибки

### Запуск тестов

```bash
npm install
npm test
